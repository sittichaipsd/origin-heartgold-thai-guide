หมายเหตุ
- คู่มือนี้ยังอยู่ระหว่างตรวจทาน บางหัวข้อเป็นการสรุปจากต้นฉบับ ไม่ได้ถอดรายละเอียดทางเทคนิคทุกบรรทัด
- คงชื่อเมือง ตัวละคร Pokémon ไอเทม ท่า และตัวเลือกบทสนทนาที่จำเป็นเป็นภาษาอังกฤษ เพื่อให้ค้นหาและทำตามในเกมได้สะดวก
- คำเตือนเรื่องบั๊กและผลทดสอบบน Emulator อ้างอิงจากคู่มือต้นฉบับ ไม่ได้หมายความว่าผู้จัดทำคำแปลภาษาไทยทดสอบทุกกรณีด้วยตนเอง
- ก่อนใช้เล่นจริง ควรตรวจสอบว่าเวอร์ชัน ROM ตรงกับคู่มือ โดยเฉพาะเควสต์ที่พลาดแล้วกลับมาทำใหม่ไม่ได้

การจัดลำดับเนื้อหา (v6)
- บท 1–13 แบ่งเป็น 3 หมวดในแต่ละบท: Main Story (เนื้อเรื่องหลัก) → Side Quest (เนื้อเรื่องเสริม) → Post-Game (เนื้อเรื่องหลังเกม) แต่ละหมวดมีแถบสีของตัวเอง (หมวดที่ไม่มีเควสต์จะไม่แสดง)
- เควสต์ที่ต้องรอหลัง Hall of Fame ครั้งสุดท้ายถูกย้ายไปหมวด Post-Game ส่วนท่อนที่ปนอยู่ในเควสต์ต้นเกม 3 จุด (บท 1 ข้อ Pidgeot และ Romance route, บท 3 Zapdos) ถูกแยกเป็นข้อใหม่ พร้อมลิงก์ชี้ไปมา
- id ของเควสต์เดิมไม่เปลี่ยน ที่ติ๊กเสร็จแล้วในเบราว์เซอร์จึงยังอยู่ครบ
- ตัวกรองอยู่ที่หัวทุกบท (1–13): กรองตามหมวด (เนื้อเรื่องหลัก/เสริม/หลังเกม) หรือ "พลาดได้ / มีเงื่อนไขเวลา" และกรอง Starter ในบทที่มีเควสต์เฉพาะ Starter (บท 1 และ 3) ตัวกรองจะซ่อนแถบหัวหมวดและรายการในสารบัญข้างที่ไม่ตรงเงื่อนไขด้วย (assets/filters.js)
- ตัวกรอง Starter มีครบทุกบท (1–13) แต่เควสต์ที่กรองออกได้จริงมีเฉพาะที่ขึ้นกับ Starter ชัดเจน (บท 1 และ 3)
