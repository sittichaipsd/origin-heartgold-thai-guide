# Water Master — Pokémon Origin HeartGold Thai Guide

คู่มือภาษาไทยสำหรับ Pokémon Origin HeartGold อ้างอิงโครงสร้างและข้อมูลจากคู่มือภาษาอังกฤษ v4.0.3

## วิธีเปิดใช้งาน

- เปิด `index.html` ในเบราว์เซอร์ หรืออัปโหลดโฟลเดอร์นี้ไปยัง static web hosting โดยคงโครงสร้าง `assets/` และ `chapters/` ไว้
- ใช้สารบัญหน้าแรกเพื่อเปิดบทที่ต้องการ
- ชื่อ Pokémon, สถานที่, ไอเทม และท่าโจมตีคงเป็นภาษาอังกฤษเพื่อให้ค้นหาในเกมได้ง่าย

## หมายเหตุ

เนื้อหาเป็นคู่มือเรียบเรียงจากแหล่งอ้างอิง ไม่ใช่การรับรองว่าทุกเหตุการณ์ผ่านการทดสอบใน ROM จริงครบทุกเงื่อนไข หากพบความแตกต่างระหว่างคู่มือกับเกม ควรยึดพฤติกรรมของ ROM เวอร์ชันที่เล่นและตรวจเงื่อนไขของเควสต์นั้นเพิ่มเติม
